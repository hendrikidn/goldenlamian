PROPOSAL MIGRASI PWA ABSENSI KE VPS CONTABO

Analisis Arsitektur Sistem, Kepatuhan Regulasi Layanan, Pemahaman Teknologi PWA, dan Roadmap Migrasi
Sistem: Golden Lamian Attendance System
Status: Rekomendasi Kritis (High Priority)
Target Server: VPS Contabo (Debian/Ubuntu)
🚨 Masalah Utama & Faktor Paling Kritis Kenapa Harus Pindah

Alasan terpenting dan paling mendesak untuk segera memindahkan PWA dari GitHub Pages ke VPS Contabo adalah karena pelanggaran resmi terhadap Ketentuan Layanan (Terms of Service) GitHub.

“GitHub Pages is not intended for or allowed to be used as a free web-hosting service for commercial business... or heavily burdened transactions.” — Sumber Resmi: GitHub Pages Usage Limits & Acceptable Use (docs.github.com)

Sistem absensi Golden Lamian digunakan oleh ratusan hingga ribuan karyawan di puluhan gerai secara komersial dan simultan. Mempertahankan sistem pada GitHub Pages menimbulkan ancaman langsung terhadap keberlangsungan operasional harian:

1. Risiko Suspensi Sepihak

GitHub menjalankan bot otomatis pendeteksi anomali trafik komersial. Repositori atau akses Pages dapat ditutup / disuspend seketika tanpa peringatan jika terdeteksi trafik operasional bisnis rutin.

2. Kelumpuhan Absensi Cabang

Bila GitHub Pages dimatikan mendadak saat pergantian shift jam sibuk (07:00, 15:00, 22:00), seluruh karyawan di seluruh outlet gagal membuka PWA, menyebabkan kekacauan rekapitulasi data kehadiran.

3. Pelanggaran Kepatuhan TI

Mengoperasikan infrastruktur inti korporasi di atas platform gratisan non-komersial melanggar standar tata kelola TI (IT Governance), audit kepatuhan, serta standar kesinambungan bisnis (Disaster Recovery).

📱 Memahami Teknologi: Apa Itu PWA (Progressive Web App)?

Progressive Web App (PWA) adalah teknologi aplikasi web modern yang menggabungkan kemudahan distribusi situs web (akses instan melalui tautan/URL tanpa instalasi via App Store) dengan kapabilitas handal aplikasi native (seperti aplikasi Android/iOS).

⚡ 1. Zero App Store Installation

Karyawan tidak perlu mencari atau mengunduh APK besar dari Google Play Store / Apple App Store. Cukup membuka tautan di browser HP, lalu memilih tombol "Install / Add to Home Screen". Aplikasi langsung terpasang di layar utama HP dalam 2 detik.

🔄 2. Service Worker & Offline-First

PWA ditenagai oleh skrip latar belakang (sw.js) yang menyimpan file aplikasi, logika kode, serta model AI wajah ke memori internal HP. Jika outlet berada di blank spot (seperti basement mall), PWA tetap dapat terbuka dan memindai wajah secara offline.

📷 3. Akses Sensor Perangkat Keras

PWA dapat mengakses kamera depan untuk verifikasi wajah & deteksi kedipan mata (Eye Aspect Ratio liveness), GPS HP untuk geofencing radius outlet (Haversine), dan penyimpanan lokal (IndexedDB) untuk antrean absen.

🔗 4. Korelasi PWA dengan Server Hosting

Saat karyawan pertama kali memasang PWA, browser wajib mengunduh seluruh App Shell dan file model AI biometrik (~7 MB). Kecepatan, stabilitas, dan keandalan web server (seperti Nginx di VPS Contabo) menjadi faktor mutlak keberhasilan instalasi.

🏛️ 1. Arsitektur Sebelum Pindah (Kondisi Eksisting: GitHub Pages)

Pada kondisi eksisting, front-end PWA dan seluruh aset model AI biometrik (~7 MB) diletakkan di GitHub Pages. Karyawan mengunduh aset tersebut dari CDN global GitHub, sementara validasi data diteruskan ke Google Apps Script (GAS) dan Google Sheets.

🚀 2. Arsitektur Sesudah Pindah (Target State: VPS Contabo)

Dengan berpindah ke VPS Contabo, aplikasi PWA berada di bawah kendali penuh server mandiri berkinerja tinggi. Web Server Nginx melayani PWA dengan protokol modern (HTTP/2), kompresi data (Gzip/Brotli), dan aggressive caching untuk model biometrik AI.

💡 4. Alasan Teknis Pendukung Migrasi ke VPS Contabo

1. Caching Model AI Wajah (face-api.js)

File bobot neural network (4.2 MB + 2.2 MB) dapat dikonfigurasi dengan header Nginx Cache-Control: public, max-age=31536000, immutable. Karyawan hanya mengunduh 1 kali dan kamera langsung aktif instan.

2. Pondasi Menghapus Masalah Google Sheets

Google Apps Script lambat (2-5 detik) dan Google Sheets rawan mengalami lock timeout saat puluhan karyawan absen bersamaan di jam sibuk. VPS Contabo siap menampung database SQL berkecepatan milidetik.

3. Efisiensi Biaya Ekstrem (Cost-to-Performance)

Contabo Cloud VPS S menawarkan 4 vCPU, 8 GB RAM, dan 200 GB SSD hanya ≈ $5.50 / bulan. Kapasitas ini sangat besar dan dapat menangani trafik ratusan outlet Golden Lamian dengan biaya sangat hemat.

4. Kesiapan Disaster Recovery & Backup

Dengan VPS, Anda dapat menjalankan automated daily snapshot dan backup berkala ke cloud storage mandiri, memastikan kepemilikan dan kedaulatan data operasional 100% berada di tangan perusahaan.

📋 5. Rencana & Roadmap Tahapan Migrasi Teknis

  1. Fase 1 (Provisioning VPS): Setup OS Ubuntu 22.04 / 24.04 LTS pada VPS Contabo, instalasi Nginx, Git, Certbot SSL, dan pengaktifan Firewall UFW.
  2. Fase 2 (Deploy Front-End PWA): Transfer file index.html, pwa_app.js, sw.js, dan folder models/ ke direktori web server (/var/www/absensi).
  3. Fase 3 (Konfigurasi Caching Nginx): Mengaktifkan kompresi Gzip/Brotli dan rules caching agresif untuk file model biometrik wajah (face-api.js).
  4. Fase 4 (Update Service Worker): Memperbarui versi cache pada sw.js agar browser HP seluruh karyawan otomatis mengunduh versi server baru.
  5. Fase 5 (Roadmap Backend Masa Depan): Membangun REST API mandiri (FastAPI/Express) di server Contabo untuk menggantikan Google Sheets secara bertahap.

🔒 6. Kesimpulan & Rekomendasi Eksekutif

1. Kebutuhan Mendesak: Pelanggaran Terms of Service GitHub Pages menempatkan operasional harian seluruh outlet Golden Lamian pada risiko fatal pemblokiran akses sewaktu-waktu. Migrasi ke VPS Contabo bukan lagi sekadar peningkatan teknis opsional, melainkan kebutuhan darurat mitigasi risiko bisnis.

2. Solusi Handal untuk PWA: Progressive Web App (PWA) sangat bergantung pada kecepatan inisialisasi awal. Hosting mandiri di Nginx VPS Contabo menjamin pengunduhan model AI wajah (~7 MB) berjalan secepat kilat dengan kompresi data dan caching lokal permanen di HP karyawan.

3. Rekomendasi Langkah Selanjutnya: Segera lakukan provisioning VPS Contabo (Cloud VPS S / M), konfigurasikan Nginx Web Server, dan arahkan distribusi PWA absensi ke server privat ini untuk memastikan kelancaran operasional dan kepatuhan penuh standar TI korporasi.
